# Classic JS Pong 

A classic 2-player 2D Pong arcade game built entirely from scratch using Vanilla JavaScript, HTML, and CSS. 

This project demonstrates fundamental game development mechanics, including an active game loop, collision detection, DOM manipulation, and asynchronous key event tracking.

## Controls

| Player | Move Up | Move Down |
| **Player 1 (Left)** | `W` | `S` |
| **Player 2 (Right)** | `Arrow Up` | `Arrow Down` |

*Note: Default browser scrolling via arrow keys is actively prevented during gameplay to ensure a smooth user experience.*

## Technologies Used

* **HTML5:** Page structure and game container rendering.
* **CSS3:** Element styling and positioning.
* **JavaScript (ES6):** Game logic, object-oriented principles (constructors for the Ball and Paddles), and event listener management.

## How to Run Locally

Since this is a client-side web application, no server installation is required.
